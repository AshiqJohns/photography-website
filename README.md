JOHNS' PHOTOGRAPHY STUDIO — Photography Website

A modern, elegant and fully responsive photography website designed to showcase creative photography, 
professional services and visual storytelling.

* About the Project

JOHNS' PHOTOGRAPHY STUDIO is a photography portfolio website built to present photography collections through 
a clean, minimal and visually engaging interface. The website focuses on elegant layouts, high-quality imagery, 
responsive design and a smooth browsing experience.

* Features

1. Home: Premium landing page with a visual hero section and featured photography.
2. About: Introduction to the studio, its creative vision and photography approach.
3. Portfolio: A curated gallery showcasing different photography categories.
4. Services: Photography packages, service descriptions and pricing information.
5. Contact: Contact form for enquiries and photography bookings.
6. Responsive Design: Optimised for desktops, tablets and mobile devices.
7. Interactive Navigation: Simple navigation with a mobile-friendly menu.
8. Modern Styling: Elegant typography, refined colours and clean layouts.

* Technologies Used
  
a) HTML5 — Website structure
b) CSS — Custom styling and visual presentation
c) Tailwind CSS — Utility-based responsive styling
d) Git & GitHub — Version control and source management
e) Vercel — Website hosting and deployment
